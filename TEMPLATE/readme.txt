Structure:

fnc: folder to store function that will be used. Function import is happening in init.sqf
fsm: folder to store fsm scripts
sound: folder to store sounds
sqf: folder to store sqf scripts

description.ext     config file of the missionFlow
init.sqf            script that will run on mission start
initBriefing.sqf    script to add diary records
missionFlow.fsm     fsm script to process mission flow. code inside runs in unscheduled (instant) environment
